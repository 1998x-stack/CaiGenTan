# 经典思维 · 现实问题的五步框架

1. 观其事：目标、现实证据、各方关切、法律与安全边界。
2. 定其义：检索真实恰切的原文而不是凭感觉套用。
3. 释其言：引用原文、前后集条号、现代汉语解释。
4. 辨其限：古代修养论中的夸张、等级关系不能不加判断照搬。
5. 行其道：提出一至三项短期能执行的行动及可验证信号。

## 三个场景

职场进退：引前集第1则，从可持续成长、职业诚信和时间代价评估，而非只看名声。重要权益不应舍弃。

人际冲突：引前集第13则，把原则问题与表达方式分开；能商量的留余地，不该忍受的侵害则设界限。

学习与反馈：引前集第5则，真有价值的批评应有事实与改善方向，羞辱和压迫不是修身训练。

若经文不适用，直接提供现代事实分析。
