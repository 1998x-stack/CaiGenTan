# 内容模型与数据质量

## 本版本的范围

固定采用维基文库电子底本所标明刻本，**前集222 + 后集134 = 356则**。其他清刻五卷、360则本不并入。原典存在不同字形、断句和编排，本站当前非最终定本。

每条数据字段：

| 字段 | 含义 |
| --- | --- |
| id | 来源内部标识，如caigen.1.1 |
| number | 本站全局1–356 |
| part | 前集/后集 |
| numberInPart | 对应版本内部条号 |
| traditional | 上游电子底本繁体 |
| original | 上游电子转录简体 |
| translation | 上游完整现代白话 |
| sourceLabel | 原始条号描述 |
| sourceHash | 上游原文内容校验摘要 |

## 阅读分段与标签

COLLECTIONS生成24个浏览分段，分别每15则为主，**不会跨前集与后集边界**；最后一段按剩余条目数显示。它们是本站便民阅读分组，不冒充原书章节。

themesFor(entry)使用原文关键词启发式推断修身、处世、进退、清心、自然、识见六种现代检索标签，非学术分类。

## 译文对应

当前最小可信对照是**一则古文对一则完整白话**，不按标点机械切割译文。一则可能包含多个句子，未来要做真实句句对照，应新增带人工审核状态的古文跨度—白话跨度映射。
