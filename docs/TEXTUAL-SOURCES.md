## 关于356与360

流传的明刻本、清刻五卷和近现代重编体例存在不同条目数量。不能因为另一来源有360条就声称本站遗漏四则；也不能将其他版本的四则拼接到本站保持同一版名。文本数量取决于特定编辑底本。

## 当前局限

1. 上游古文包含部分异体字、古字或疑似转录问题。
2. 后集第3、17、29、72、95、96则特别需要依据影印和出版校本复核。
3. 现代白话属于上游AI辅助学习稿，不是经古典文献专家逐条审定的学术定本。
4. 原文电子标点不代表洪应明亲自确定的现代句界，不强行拆成“句句严格翻译”。

## 校勘流程

固定一个可靠影印/出版校本和具体页码 → 逐字核对电子文字 → 分离异文、注释、现代编辑标点 → 审核白话含义 → 第二人交叉复核 → 记录修订与审阅状态。优先保留历史版本差异，不静默覆盖。
