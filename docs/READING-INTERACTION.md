# 原文在上 · 点击见义

每则卡片视觉与DOM结构始终如下：

1. 来源和原集条号
2. 完整古文（始终可见）
3. 可键盘操作的“轻触见义”按钮
4. 对应该则的现代白话释义（初始hidden；按钮点击后显示）
5. 编辑性主题标签、收藏和复制链接

### 交互约束

- 每则译文最初必须实际使用hidden属性，不使用模糊遮挡或覆盖层假隐藏。
- 每条按钮配aria-expanded、aria-controls和唯一对应译文id。
- 点击一条不会开启另一条；再次点击收起；“全部收起”关闭本分段全部译文。
- 切换分段重置所有译文；字号操作只改CSS属性，保持已经展开的内容。
- 简繁切换需更新古文原字显示；现代译文继续保持上游译释，未自动繁体化。
- 收藏和主题等只存本地，不上传个人信息。
- 深链#entry-N定位该则阅读卡；移动端不出现左右原译双列布局。

### 严谨标注

当前实现**一则一对**而不是伪造每句话的单独译意。由于上游白话不一定和古文每个标点句直接对应，精确句级对照需补充人工校验的句法/语义区间。
