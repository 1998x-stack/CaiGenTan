# 产品定位 · 把古典智慧还给现实生活

《菜根谭》阅读馆旨在帮助读者理解明代洪应明关于修身、处世、进退、得失与自然闲适的格言，兼顾优美排版与AI现实问题反思。

## 用户价值

- 每日随机读一则；不先展示白话，使读者先思其义。
- 检索原文、简繁文字、现代白话和主题关键词，查看前集/后集。
- 保存有启发的则文，分享对应条号链接、调整字号和主题。
- 借Skill引用真实原文，分析学习、职场和人际问题，指出现代限制并提出行动。
- 查明全部356则的电子源与现代释读的版权署名。

## 当前功能

356则成对古文白话、698张保守细分的阅读卡、24个小段落（仅网站浏览便利层）、独立点击揭晓、收藏、搜索、显示更多、繁简体、主题、随机翻阅、可访问性基础契约、静态Pages与CI。

## 不包含

未经校核的学术定本、强行逐字对译、神秘命运预测、AI自动评判用户人格、社交账户和后端用户跟踪。古文是一面镜子，不替代今天的事实与权利。

## 验收标准

源文不能丢失或错位；前后集条数必须准确；翻译初始隐藏；全宽与手机都上下呈现；署名许可显眼且完整；CI和Pages实际结果可追查。
