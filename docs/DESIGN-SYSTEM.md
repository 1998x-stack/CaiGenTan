# 设计系统：一纸清香

## 核心意象

采用宣纸背景、赭石日轮、山峦线条、细微纸张纹理表现“淡泊、有余、自然与清心”。深墨模式表现安静夜读；减少视觉噪声，确保文字阅读有高优先级。

| 用途 | 宣纸 | 深墨 |
| --- | --- | --- |
| 背景 | #f1ede2 | #16271f |
| 阅读纸面 | #faf7ef | #1b3025 |
| 主要文字 | #294038 | #edeadd |
| 次级文字 | #607267 | #c1c7b9 |
| 赭石强调 | #a56148 | #d59e7f |

- 字体：系统宋体用于古文与标题，系统无衬线用于操作控件；不分发版权字体。
- Hero：大书名、日轮、圆环、层叠远山、文言引句和简洁入口。
- 目录：三列卡片，显示前后集、主题与原文预览。
- 阅读室：左侧分段，右侧始终**一列上下的原文—隐藏释义**。
- 移动端：两列预览卡片、横向可滚分段导航，不让原译左右分栏。
- 动效：慢速浮动日轮、渐显。用户选择prefers-reduced-motion时禁用，正文仍然可见。

现代网站的排版节奏可以借鉴成熟的交互设计，但不得复制第三方标识或商业字体资源。
